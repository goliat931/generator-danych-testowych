API Generatora Danych

⚠️ Jak to działa

To jest "API" po stronie przeglądarki, nie prawdziwy serwer. Strona jest hostowana statycznie (GitHub Pages), więc dane generuje JavaScript uruchomiony w tej karcie po jej otwarciu - nie jest to kod wykonywany po stronie serwera.

Zadziała: gdy otworzysz poniższy URL (z parametrami) bezpośrednio w przeglądarce, albo w narzędziu sterującym prawdziwą przeglądarką (Playwright, Selenium, Puppeteer).
Nie zadziała: z curl, Postmana ani żadnego backendu wysyłającego zwykłe zapytanie HTTP GET - taki klient dostanie surowy plik HTML zamiast wygenerowanych danych, bo nie wykonuje JavaScriptu ze strony.
